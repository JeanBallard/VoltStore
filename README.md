# VoltStore

Веб-проект: каталог смартфонов со сравнением, ресейл (VoltResale) с модерацией объявлений и сделками, корзина, заказы и админ-панель.

**Сайт (демо):** https://voltstore666.netlify.app

## Что умеет
- Каталог флагманов: поиск, фильтры по бренду, назначению и бюджету, сравнение до трёх моделей.
- Регистрация и вход, подтверждение email, восстановление и смена пароля.
- Заказы: доставка (курьер, почта, самовывоз), статусы, трек-номер, подтверждение оплаты менеджером.
- VoltResale: объявления с фото, модерация, чаты в реальном времени, сделки между пользователями, отзывы после сделки, жалобы.
- Админ-панель: каталог, заказы, модерация, жалобы, пользователи и баны.

## Технологии
- Фронтенд: HTML, CSS, JavaScript без фреймворков.
- Бэкенд: Supabase (PostgreSQL, Auth, Storage, Realtime).
- Безопасность: правила доступа RLS и серверные функции в базе, права администратора хранятся в БД.
- Хостинг: Netlify.

## Структура
```
index.html, styles.css, app.js   интерфейс и логика демо-режима
live.js                          подключение к Supabase (боевой режим)
config.js                        адрес проекта Supabase и публичный anon-ключ
supabase/schema.sql              таблицы, политики доступа, функции
supabase/seed_products.sql       начальный каталог
supabase/functions/              заготовки платёжных функций (для будущей онлайн-оплаты)
```

## Статус
Учебный проект. Онлайн-оплата не подключена (оплату подтверждает администратор вручную). Продавцы и отзывы в примерах демонстрационные.
